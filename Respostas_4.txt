CONEXÃO:

Como C# realiza uma conexão com um banco de dados?
1- Através de uma biblioteca/driver que criar comandos para possibilidar essa conexão.

Qual biblioteca/driver é utilizado pelo banco escolhido?
2- MySqlConnector.

Como essa biblioteca é adicionada ao projeto?
3- Com o dotnet add package.

O que é uma string de conexão?
4- É uma string que são colocados dados do banco de dados para o sistema conseguir conetar a ele.

Quais informações normalmente aparecem em uma string de conexão?
5- O servidor,o banco, o usuário e a senha.

COMANDOS SQL:

1- Como realizar o INSERT, SELECT, UPDATE, DELETE:
. Se o comando retorna linhas de dados (SELECT) você irá usar ExecuteReader().
Se o comando só altera dados, sem devolver alguma linha (INSERT, UPDATE, DELETE) você deverá usar ExecuteNonQuery(). Ele te devolve apenas um número: quantas linhas foram afetadas.

1- O que são parâmetros em comandos SQL e por que eles são importantes?
. São place Holder para os atribudos que serão colocado neles, para evitar erros e facilitar o colocamentos de itens na tabela.

2- Explique também o que pode acontecer quando um sistema monta comandos SQL diretamente utilizando textos digitados pelo usuário.
. Textos deretos podem causar SQL INJECTION, permitindo comandos maliciosos no banco.
