Banco de dados utilizado;
O banco de dados utilizado foi o Mysql

Biblioteca/driver utilizado;
O driver usado foi o MysqlConnector

Como instalar as dependências;
Digitando "dotnet add package MySqlConnector" no terminal

Como configurar o banco;
Para o banco de dados copie do ronaldo.sql e cole no mysql

Como executar o projeto;
Para rodar o sistema aperte Ctrl+j e digite dotnet run

Breve explicação de como funciona a conexão.
Através da connectionString o sistema pega informações do banco para se conectar e assim consegue executar os códigos
